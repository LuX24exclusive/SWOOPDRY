# Swoopdry website

## Run locally
Open `index.html` in a modern browser.

## Publish with GitHub Pages
1. Upload `index.html` to the root of your GitHub repository.
2. Open the repository's **Settings → Pages**.
3. Under the build/deployment settings, select **Deploy from a branch**.
4. Choose your main branch and the `/ (root)` folder, then save.
5. Wait for GitHub Pages to publish the site and open the provided URL.

The reveal animation is now optional, so content remains visible if JavaScript animation support is unavailable.
